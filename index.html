PredictPilot, a channel predictor for 5G base stations

A 5G base station needs an up-to-date picture of each user's radio channel to aim its beams, but it can only sound a few users in each slot.

PredictPilot forecasts every user's channel up to 32 slots ahead from the pilots it has already received, and estimates how uncertain each forecast is. That uncertainty decides who gets the next pilots, and how much weight each prediction gets in the precoder.

The prediction loop

From pilots to beams. Point at a stage to see what it does.

  1. SRS pilots. Each user's past sounding signals, which arrive at irregular times.
  2. ConvLSTM encoder. Turns that pilot history into a compact state for each user.
  3. Diffusion transformer. Generates the forecast of each user's future channel.
  4. Channel forecast. The predicted channel for each user, up to 32 slots ahead.
  5. Uncertainty. An estimate of how far each forecast can be trusted.
  6. SRS scheduler. Gives the next pilots to the users where they help most.
  7. WMMSE precoder. Aims the beams, weighting each predicted channel by its uncertainty.

Aug 2025 – Present

Paper under review at E2A 2027, International Conference on Emerging Electronics and Automation

  • Built a model in Python and PyTorch that predicts each user's wireless channel up to 32 slots ahead in a massive MIMO system, using a ConvLSTM encoder and a diffusion transformer trained on irregular pilot history.
